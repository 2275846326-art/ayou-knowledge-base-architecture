# ayou知识库系统架构

原作者：阿柚

把自己的资料、Agent 的蒸馏成果和使用中的反馈放进同一个知识库。你可以只用熟悉的 Agent，也可以使用 Windows 工作台管理原文、任务和成果。

| 使用方式 | 从哪里开始 |
| --- | --- |
| 用自己的 Agent | 下载仓库内容，打开[从这里开始](从这里开始.md)，用自己的资料试一次有出处的回答 |
| 用 Windows 工作台 | 前往[官方发行页](https://github.com/2275846326-art/ayou-knowledge-base-architecture/releases)，查找 Windows 安装包 |

蒸馏成果可以转为学习页。先看结构图理解内容，再顺着引用回读原文，尝试复述、找边界，或把方法迁移到手头的任务。工作台支持导出离线 HTML，具体入口见[从这里开始](从这里开始.md#从蒸馏成果生成学习页)。
